# رفيق المسلم — Muslim Companion

واجهة React عربية RTL لتطبيق مساعد يومي للمسلم، مبنية بطريقة قابلة للتوسعة.

## التشغيل

```bash
npm install
npm run dev
```

لفحص نسخة الإنتاج:

```bash
npm run build
npm run preview
```

## التقنيات

- React + Vite
- React Router لإدارة الصفحات
- Context API لمشاركة المهام والأذكار والمظهر
- Custom Hooks لجلب مواقيت الصلاة والقرآن وتحديث عنوان الصفحة
- `localStorage` لحفظ الحالة محليًا
- Lucide React للأيقونات
- AlAdhan API لمواقيت الصلاة وAlQuran Cloud API لقائمة السور والآيات

## بنية المشروع

```text
src/
├── components/
│   ├── layout/       # Sidebar, Topbar, MobileNav, AppLayout
│   └── ui/           # مكونات صغيرة قابلة لإعادة الاستخدام
├── context/          # AppContext: الحالة العامة والإجراءات
├── data/             # بيانات الأذكار وأسماء الصلوات
├── hooks/            # usePrayerTimes, useQuran, usePageTitle
├── pages/            # صفحات التطبيق
├── styles/           # CSS العام والثيمات والاستجابة
├── utils/            # تنسيقات التاريخ والترحيب
├── App.jsx
└── main.jsx
```

## ملاحظات مهمة قبل التوسعة

1. **البيانات الدينية:** محتوى الأذكار المرفق أولي للواجهة ويجب مراجعته وتوثيق مصادره من مراجع موثوقة قبل النشر.
2. **مواقيت الصلاة:** افتراضيًا المدينة Cairo والدولة Egypt وطريقة الحساب `method=5`. غيّر طريقة الحساب وفق الجهة المحلية التي تعتمدها.
3. **القبلة:** الحساب تقريبي اعتمادًا على إحداثيات المتصفح، ويحتاج إذن الموقع. لا يعتمد على حساس البوصلة.
4. **الإحصائيات:** الرسم الأسبوعي توضيحي حاليًا. لتقديم إحصائيات فعلية، أضف سجلًا مؤرخًا للإنجازات.
5. **الحفظ:** المهام والعدادات والثيم تحفظ على نفس المتصفح والجهاز فقط؛ لا توجد مصادقة أو مزامنة سحابية.
6. **API:** تحتاج وظائف القرآن ومواقيت الصلاة إلى اتصال إنترنت. أضف حالات إعادة المحاولة والتخزين المؤقت عند تطوير نسخة إنتاجية.

## أفكار تطوير مقترحة

- حفظ آخر سورة وآخر آية تمت قراءتها.
- اختيار مدينة عبر قائمة بدل إدخالها نصيًا.
- استكمال مكتبة أذكار موثقة مع عدّاد مستقل لكل ذكر.
- تخزين سجل الإنجاز حسب التاريخ وحساب الإحصائيات الأسبوعية والشهرية.
- إضافة اختبارات للمكونات والـ hooks.
- إضافة PWA والإشعارات بعد ضبط الأذونات وتجربة المستخدم.
